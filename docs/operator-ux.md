# 운영자 UX 원칙

KickON Data Center는 개발 도구가 아니라 운영 판단 도구입니다. 구현 용어보다 지금 확인하고 처리해야 할 일을 먼저 보여줍니다.

## 우선순위

1. 실패한 동기화와 시스템 위험
2. 사용자가 기다리는 미처리 1:1 문의
3. 미처리 신고와 숨김이 필요한 콘텐츠
4. 정지·경고가 필요한 반복 위반 사용자
5. 오래되거나 외부 원본과 다른 축구 데이터
6. 정상 상태와 참고 지표

대시보드의 `지금 확인할 일`은 최대 4건만 보여주고 각 항목에는 한 가지 다음 행동을 제공합니다.

## 안전한 쓰기

- 대상, 현재 상태, 영향, 변경 사유를 함께 확인합니다.
- 문의의 내부 메모와 사용자 답변을 분리합니다.
- 콘텐츠는 삭제하지 않고 숨김·복원합니다.
- 사용자 정지는 종료 시각과 근거가 필요하며 최대 365일입니다.
- 수동 데이터는 외부 원본과 차이를 보여준 뒤 일회성 적용 또는 잠금 보호를 구분합니다.
- 모든 중요한 변경은 작업자와 사유를 감사 로그에 남깁니다.
- 실패 메시지는 원인을 추정하지 않고 다음 확인 위치를 제공합니다.

## 정보 표현

- `확인 필요`를 `0` 또는 `정상`으로 표현하지 않습니다.
- 상태는 색뿐 아니라 텍스트를 함께 표시합니다.
- 표의 원문은 줄바꿈/요약하고 상세 페이지에서 전체 내용을 보여줍니다.
- 기술 ID는 보조 정보로 두고 닉네임·팀·선수명 같은 운영 식별자를 우선합니다.
- 키보드 포커스, skip link, Radix 대화상자의 focus trap을 유지합니다.

## 선수 정보

- 선수 사진을 조회·표시·업로드·수정하지 않습니다.
- 이니셜 아바타도 만들지 않습니다.
- 이름, 소속 팀, 등번호, 포지션으로 식별합니다.
- 모바일·동기화 호환을 위해 기존 `image_url` 컬럼 자체는 제거하지 않습니다.

## 색상과 밀도

기준은 `src/app/globals.css`의 의미 토큰입니다.

- 다크 기본: 배경 `#060b12`, 카드 `#0d1622`, 보조 면 `#121e2c`, 테두리 `#203044`, KickON 블루 `#2b95f6`
- 라이트: 차가운 블루·그레이 토큰을 유지합니다.
- 브랜드 블루는 선택·링크·주요 실행에 사용합니다.
- 성공·주의·위험 색은 실제 상태 의미에만 사용합니다.
- 장식용 그라데이션·글로우·큰 그림자·카드 남발을 피합니다.
- 데스크톱 고밀도 표는 44~48px 행 높이, 모바일 조작 대상은 최소 44px을 기준으로 합니다.
