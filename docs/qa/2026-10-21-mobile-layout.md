# 모바일 관리자 화면 개선

모바일에서 직관 인증은 경기·사용자, 공지·문의·신고는 제목·상태를 중심으로 표시한다. 데이터·운영 관리 메뉴는 공통 선택 상자로 전환한다. 제목과 동작 버튼은 같은 줄, 검색·필터는 다음 줄에 배치한다.

자동 동기화와 실행 내역, 푸시 설정·발송 내역, 경기 일정, 구단 순위와 선수 목록의 모바일 최소 너비를 해제하고 주요 정보를 화면 안에 배치한다. 숨긴 항목은 기존 상세 화면으로 확인하며 선수 정렬은 별도 모바일 선택 상자로 유지한다. 알림 설정의 부분 설정·확인 불가, 미집계 값은 그대로 보존한다.

운영 요약 카드 세 개는 한 줄을 유지하고 구분선과 숫자 간격을 16px로 넓힌다.

검증: 단위 검사 213개, lint, TypeScript 및 Vite 빌드, 공개 배포 파일 검사 통과. 브라우저 기능 검사 174개는 최초 실행의 화면 선택자 불일치를 수정한 뒤 관련 재검사를 포함해 모두 통과했다. 320·360·390·768px 라이트·다크 화면 및 상세 모달 200개 조합에서 페이지와 내부 수평 스크롤이 없었다. 마지막 요약 카드 간격은 320·360·390px에서 두 테마로 추가 확인했다.

브라우저 검사는 로컬 모의 인증·데이터를 사용했다. 실제 계정 비밀번호, 운영 게시글 수정·알림 발송·동기화는 QA에 사용하지 않았다. 이 변경은 화면 배포만 포함하며 서버 비밀 값이나 DB 변경은 없다.
