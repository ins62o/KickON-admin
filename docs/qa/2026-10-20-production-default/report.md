# 로그인 후 기본 운영 환경

운영 공개 연결이 설정되어 있으면 기본 작업 환경을 운영으로 선택한다. 로컬 개발 모드에도 같은 규칙을 적용하며, 기존 개발 계정으로 인증하고 대상 환경의 활성 관리자 권한을 확인하는 통합 로그인은 유지한다. 공개 연결이 개발만 구성된 설치는 개발을 유지한다. 로그인 후 사용자가 명시적으로 선택한 환경 주소는 계속 지원한다.

기존 KICKON_ENVIRONMENT 설정은 일반 공개 키가 속한 연결을 구분하는 데 유지한다. 기본 화면을 운영으로 바꾸면서 개발 공개 연결이 운영 연결로 잘못 배정되지 않도록 검증한다.

- 단위 테스트 213개, lint, 타입 검사, Vite 빌드 통과
- 현재 로컬 서버의 기본 주소에서 운영 환경 로그인·양쪽 로그아웃·3회 재로그인 및 새로고침 검증 통과
- 대상 관리자 권한 거절 시 양쪽 세션 삭제 검증 통과
- 브라우저 검증은 외부 인증 응답을 모의 처리했으며 실제 사용자 비밀번호는 사용하지 않음
