# 앱 업데이트 UI 최종 개발 배포 및 운영 준비

## 최종 UI

- 데이터 관리 카드의 포인터 커서와 원형 버튼을 유지한다.
- Google Play / App Store 버전을 일반 입력창에서 수정한다. 유효한 버전이 저장값과 다를 때만 저장 버튼을 활성화한다.
- 변경 사유 입력과 안내 표시 체크박스를 제거했다. 저장은 enabled=true 및 설정 요약 사유로 기존 RPC를 호출한다.
- 입력을 바꾼 동안만 취소 버튼을 표시한다. 마지막 저장 취소는 이전 설정 복원으로 표시하고 기존 RPC를 사용한다.
- 이력은 뱃지와 상세 이동 없이 스토어 이름, 버전 변경, 시간/역할을 표시한다. 페이지당 3개, 목록 높이 330px, 4개부터 목록 상단 페이지 이동을 표시한다. 조회 범위는 기존 최근 50건이다.

## 실제 개발 설정

사용자 요청에 따라 실제 개발 DB에 Google Play(Android) 1.0.0, App Store(iOS) 1.0.2를 저장했다. 두 플랫폼 모두 enabled=true다. 새로고침해 저장값을 재조회했으며 감사 ID 78(Android), 79(iOS)가 생성됐다. 로컬 미리보기의 모의 데이터 변경이 아니라 기존 관리자 세션 및 admin_set_app_store_release를 통한 실제 개발 설정 저장이다.

개발 DB에는 기본 테이블, 저장 RPC, 복원 RPC가 이미 수동 적용돼 있다. 기존 문서에 기록한 migration 이력 등록 정리는 배포와 별도다.

## 운영 읽기 검증

운영 프로젝트 smihjaucucffmsbktnmp를 SQL Editor에서 읽기 전용으로 조회했다.

- app_store_releases 및 admin_set_app_store_release(text,text,boolean,text) 존재.
- migration 이력 202609160003, 202609160004 존재.
- admin_cancel_app_store_release(text,bigint,text) 및 202609170001 이력 없음.
- 운영 버전 설정은 0건.
- 활성 안내 공개 조회 및 관리자 조회 정책 존재. anon/authenticated 직접 쓰기 금지, authenticated 저장 RPC 실행 허용, anon 저장 RPC 실행 금지.
- 최근 운영 배포 실행 35115244947은 성공했으며 커밋은 966d699cee94a1f8ff8644b0c1a0a1b4eed802b3이다. 최종 UI와 복원 기능 커밋은 이 배포에 포함되지 않았다.

## 운영에 남은 작업

1. 운영 DB에 202609170001_cancel_app_store_release.sql만 적용하고 실행 권한, migration 이력, PostgREST 갱신을 확인한다. 기본 테이블 생성 migration을 다시 실행하지 않는다.
2. 검증한 Dev 변경을 Prod에 반영해 기존 운영 Actions 배포를 실행한다. DB migration은 워크플로가 자동 적용하지 않는다. 운영 워크플로는 정적 콘솔과 개발/운영 Lambda를 함께 배포하며 development/ 정적 경로는 삭제 대상에서 제외한다.
3. 운영 어드민에서 실제 출시 버전을 플랫폼별로 등록한다. 개발의 1.0.0/1.0.2 설정이 운영에 자동 복사되지 않는다.
4. 출시 앱 바이너리에 버전 조회와 홈 라벨 기능이 포함됐는지 확인한다. 현행 모바일 소스에는 기능이 있으나 기존 스토어 바이너리 포함 여부는 소스 검증만으로 확정할 수 없다. 미포함이면 새 앱 출시가 필요하다. 실기기에서 하위/동일/상위 버전, 홈 재진입/앱 복귀 및 스토어 이동을 검증한다.

이번 요청에서는 운영 DB/설정 변경과 운영 배포를 실행하지 않는다.

## 개발 배포 결과

커밋 5203eeda1ff03985a9733df19d8c1c446846f04f, Actions 실행 35115938410에서 검증 및 개발 정적 콘솔/개발 Lambda 배포 성공. 운영 job은 skipped. 배포된 https://admin.kickon.kr/development/data-management/?appUpdates=1 에서 실제 저장 버전, 수정 시 저장 활성화, 취소 시 원래 값과 비활성 상태 복원, 뱃지/링크 없는 이력 3건을 확인했다. 이 확인 중 버전 설정을 추가 저장하지 않았다. 현재 이력이 3건이므로 4건 이상 페이지 이동의 실서버 브라우저 검증은 수행하지 않았다.
