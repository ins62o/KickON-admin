# Migration 실행 보류
현재 승인된 실행 SQL은 없다. 이 디렉터리에 역사152개나 증분29개를 복사해 CLI로 실행하지 않는다.
보존 원문·원래 버전·SHA는 preserved/admin/manifest.json에 있다. 실제 적용 이력·권위 원본·발행 책임자는 미확정이다.
SQL 파일이 없다는 사실은 DB 초기화·안전한 연결·적용 성공을 뜻하지 않는다. CLI는 SQL이 없어도 연결을 시도할 수 있으므로 별도 승인 없이 호출하지 않는다.
운영 CI에는 Migration 실행 단계가 없다. 새로운 실행 이력은 권위 검증과 별도 정방향 변경 승인으로만 만든다.
